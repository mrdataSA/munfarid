# رزق (RIZQ): ناقل أخبار الوظائف السعودية (نسخة محلية)

خدمة مجانية تنقل أخبار الوظائف من مصادرها، ومع كل وظيفة رابط إعلانها الأصلي. رزق لا يستقبل طلبات التوظيف، ولا يعرض إعلانات تجارية.

## التشغيل
1. اضغط مرتين على `start.bat`.
2. يفتح المتصفح تلقائياً على `http://localhost:8080`.
3. اترك النافذة السوداء مفتوحة: هي اللي تشغّل الموقع وتجمع الوظائف كل 3 ساعات وتشغّل بوت تيليجرام.
4. للإيقاف: أغلق النافذة السوداء.

## بوت تيليجرام (الواجهة الأساسية)
1. افتح @BotFather في تيليجرام، اكتب `/newbot`، واختر اسماً ومعرّفاً ينتهي بـ bot.
2. انسخ التوكن والمعرّف إلى `.env`:  `TELEGRAM_BOT_TOKEN=...` و `TELEGRAM_BOT_USERNAME=...` (بدون @)
3. أعد تشغيل `start.bat`.

**للباحث عن عمل** (محادثة خاصة مع البوت):
- يكتب مسمى وظيفي أو أكثر (مثل: محاسب، accountant) فتصله كل الوظائف المطابقة، الأحدث أولاً، 8 في كل رسالة مع زر «عرض المزيد».
- نبحث تلقائياً بالأسماء الأخرى لنفس الوظيفة (ذكاء اصطناعي + قائمة جاهزة).
- يرسل سيرته (PDF أو Word أو نص) فنقترح وظائف حسب مهامه وخبراته. نحذف البيانات الشخصية قبل القراءة، ولا نحفظ الملف ولا النص.
- الأزرار: وظائفي، مسمياتي، سيرتي، المصادر (كل المصادر أو مصادر يختارها)، التنبيهات (يومياً الساعة 9 أو فوراً، والمدينة).
- `/delete` يحذف كل بياناته.

**للقروبات والقنوات:** أضف البوت مشرفاً، ثم اكتب `/feed` (كل الوظائف) أو `/feed محاسب، مهندس مدني`. ينشر وظيفة كل 45 ثانية على الأكثر، وبحد يومي (`BOT_FEED_DAILY_CAP`، الافتراضي 80). للإيقاف: `/unfeed`.

## الإعدادات (ملف `.env`)
افتح ملف `.env` بالمفكرة (Notepad)، عدّل القيمة بعد علامة `=`، احفظ، ثم أعد تشغيل `start.bat`.

### تفعيل الذكاء الاصطناعي (Groq، مجاني)
1. ادخل https://console.groq.com/keys وسجّل بحساب Google.
2. اضغط **Create API Key** وانسخ المفتاح.
3. الصقه في `.env`:  `GROQ_API_KEY=المفتاح`

يحسّن فرز منشورات تيليجرام (وظيفة أو إعلان)، واستخراج المسمى والشركة والمدينة، واستخراج المهارات من السيرة الذاتية.

ويصنّف الوظائف اللي ما عرفت القواعد تخصصها («أخرى») ويستخرج مهاراتها، لأن التنبيه ما يوصل إلا لوظيفة تخصصها معروف. يشتغل قبل إرسال التنبيهات (16 وظيفة جديدة لكل مصدر) وبعد كل جولة كاملة (120 وظيفة قديمة)، ضمن الحد اليومي المجاني.

النموذج: `GROQ_MODEL=openai/gpt-oss-120b`، والاحتياطي `openai/gpt-oss-20b`. نماذج Llama القديمة أوقفتها Groq.

### تفعيل بوت تيليجرام (مجاني)
1. في تيليجرام افتح **@BotFather** وأرسل `/newbot`.
2. اختر اسماً (مثل: رزق للوظائف) ثم معرّفاً ينتهي بـ bot (مثل: `RizqJobsBot`).
3. انسخ التوكن، وضعه في `.env`:
   ```
   TELEGRAM_BOT_TOKEN=التوكن
   TELEGRAM_BOT_USERNAME=RizqJobsBot
   ```
4. أعد التشغيل. سيظهر للمشترك زر «اربط تيليجرام» في صفحة «تنبيهاتي».

### LinkedIn
مفعّل (`LINKEDIN_ENABLED=1`) بناءً على الإذن المكتوب، احتفظ به.
- **يجمع كل وظيفة تنشر في السعودية**، بدون كلمات بحث: كل ساعة يقرأ الوظائف المنشورة منذ آخر جولة، الأحدث أولاً، ويوقف أول ما يوصل لوظيفة شافها قبل.
- لو توقف فترة (حظر أو إطفاء الجهاز) يكمل المتأخر في الجولات التالية، حتى 3 أيام للخلف.
- بطيء ومهذب: 20 إلى 40 ثانية بين الصفحات، وحد يومي `LINKEDIN_DAILY_CAP=240` طلب (المتوقع 100 إلى 150).
- عند رسالة «طلبات كثيرة» (429) يتوقف 3 ساعات، وتتضاعف لين 24 ساعة إذا تكررت. عند طلب تسجيل الدخول يتوقف 24 ساعة.
- مرة يومياً يقرأ عدد LinkedIn نفسه لوظائف آخر 24 ساعة، عشان نعرف نسبة التغطية (تظهر في لوحة الإدارة).

### التخصصات
40 تخصص في 8 مجموعات قريبة من تصنيف LinkedIn (`backend/normalize.py`: `SPECIALTY_GROUPS`). التنبيه يوصل كاملاً للتخصص نفسه، وجزئياً لتخصص من نفس المجموعة. أسماء التخصصات القديمة تبقى تشتغل للمشتركين القدامى.

### للطلاب: التدريب التعاوني والابتعاث
- `#/coop` و`#/scholarships`: برامج الجهات الحكومية والشركات السعودية والعالمية، بموعد الفتح المعتاد والشروط والرابط الرسمي.
- البيانات في `collectors/research/coop_programs.json` و`collectors/research/scholarships.json` (عدّلها مباشرة، وتظهر فوراً).
- `collectors/programs_watch.py` يفحص الصفحة الرسمية لكل برنامج كل 3 أيام، ولو صارت تقول إن التقديم فتح ينبّه المشتركين اللي اختاروا تنبيهات الطلاب.

### سرعة التنبيهات (المسار السريع)
- كل مصدر يُحفظ ويُرسل تنبيهه فور انتهائه، بدون انتظار نهاية الجولة.
- كل `FAST_COLLECT_MINUTES=60` دقيقة جولة خفيفة لقنوات تيليجرام وأحدث وظائف LinkedIn (المصادر التي فيها `"fast": true`).
- الحد: 5 وظائف لكل مشترك في الجولة، و20 في اليوم.

### X (تويتر)
لا نسحب موقع X: ملف robots عندهم يمنع كل البرامج، والسحب يحتاج تسجيل دخول وتجاوز حماية. الطريق الوحيد هو الواجهة الرسمية، وصارت بالدفع حسب الاستخدام (حوالي 0.005 دولار للمنشور). أنشئ حساباً في https://console.x.com واشحن رصيداً ثم ضع `X_BEARER_TOKEN=`. الحد اليومي `X_DAILY_POST_CAP=300` منشور (حوالي 1.5 دولار يومياً)، ولا ندفع لنفس المنشور مرتين.

### Careerjet وJooble (مجانيان، يغطيان Indeed وبيت وNaukrigulf وغيرها بشكل نظامي)
- **Careerjet:** سجّل كناشر في https://www.careerjet.com.sa/partners/register/as-publisher ثم ضع المفتاح: `CAREERJET_API_KEY=المفتاح`
- **Jooble:** اطلب مفتاحاً من https://sa.jooble.org/api/about ثم ضعه: `JOOBLE_API_KEY=المفتاح` (الخطة المجانية 500 طلب إجمالاً، ونستهلك طلبين فقط في كل جولة).
- الاثنان يجيبان وظائف السعودية فقط، ويعملان آخر الجولة حتى تبقى الوظيفة الموجودة عندنا من مصدرها الأصلي برابطها الأصلي.

### Playwright (لقراءة جدارات وبوابات البنوك)
مثبّت مسبقاً. إن نقلت المشروع لجهاز آخر: `pip install playwright pypdf` ثم `python -m playwright install chromium`.

### Scrapling (اختياري: إصلاح تلقائي عند تغيّر تصميم موقع)
`pip install "scrapling==0.4.15" "w3lib<2.3"`. نستخدم المحلّل فقط، ولا نستخدم أبداً خيارات التخفي أو تخطي Cloudflare أو البروكسي.

## المصادر
- **القائمة الكاملة المقروءة لكل المصادر والشركات والقنوات: `docs/مصادر_الوظائف.md`**
- القائمة في `collectors/sources.json`
- المواقع الكبيرة تُقرأ صفحة بصفحة: `page_url` و`pages` (أحدث الصفحات) و`backfill_pages` و`max_pages` (صفحات أقدم بالتناوب)
- `origin_from_article: true` يفتح صفحة الإعلان ويأخذ رابط التقديم الأصلي منها
- بوابات الشركات والجهات الحكومية في `collectors/employers.json` (أضف جهة بنسخ سطر مشابه)
- الطريق الذكي: شركات على Greenhouse وLever وWorkable وAshby وRecruitee وPinpoint تُضاف بسطر واحد فيه `ats` و`board`. للشركات العالمية أضف `"strict_location": true`. نتائج الاكتشاف في `collectors/research/ats_slugs.json`
- جدارات يُقرأ بكل تبويباته: الخاص، والخدمة المدنية، وشبه الحكومي، والتعاقدي
- ملف robots يُقرأ حسب المعيار RFC 9309 (أطول قاعدة تحكم، والنجمة `*` محسوبة)
- خريطة أكبر 199 جهة سعودية ونتيجة فحص كل واحدة في `collectors/research/employers.json`
- قنوات تيليجرام في `collectors/channels.txt` (قناة في كل سطر، راجعها شهرياً)
- حالة كل مصدر تظهر في لوحة الإدارة

## البيانات
- `data/store/`: الوظائف والمشتركون والإعلانات المباشرة والإعدادات (خاصة، لا تُعرض على الإنترنت)
- `data/cvs/`: ملفات السير الذاتية
- `data/backups/`: نسخة احتياطية يومية (آخر 7 أيام)
- `logs/rizq.log`: سجل التشغيل

## للمطوّر
- Python 3.10+ بمكتبات النظام فقط (بدون pip). اختياري: `pypdf` لقراءة سير PDF.
- `python run_collectors.py` جمع يدوي، و`python run_collectors.py --list` لعرض المصادر.
- `RIZQ_DATA_DIR=<مجلد>` لتشغيل الخادم على نسخة بيانات منفصلة (للاختبار).
- `python tests/test_api.py` يشغّل خادماً مؤقتاً على مجلد بيانات فارغ ويختبر كل الواجهات (لا يلمس `data/store`).
- طبقة التخزين في `backend/storage.py` معزولة، وعند الانتقال إلى Supabase تتغير هذه الطبقة فقط.
